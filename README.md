# 深時培養皿

生命演化模擬網頁遊戲原型。直接用瀏覽器打開 `index.html` 即可遊玩，不需要伺服器或安裝套件。

## 檔案結構

- `index.html`：版面與樣式（CSS 內嵌）
- `js/sim.js`：演化模擬核心（環境場、基因組、突變、代謝、捕食、物種分化與命名、標本卡解說）
- `js/draw.js`：依基因程序生成生物外觀（體節、附肢、觸手、眼睛、甲殼、棘刺、發光器、葉狀體、輻射對稱體）
- `js/ui.js`：畫面繪製、場景背景、參數滑桿、地質事件、標本卡、生命之樹、演化紀事

## 常用調整點（js/sim.js）

- `SPLIT`：物種分化門檻，調小會更常出現新物種
- `mutate()`：突變機率與幅度、大突變（體節複製、新附肢、眼點複製、觸手增生、吞噬作用）的機率
- `step()` 中的 cost / gain：各性狀的代謝成本與環境效益，是天擇方向的關鍵
- `capA` / `capH`：生產者與消費者的族群上限，影響效能與生態平衡
- `TICK_YEARS`：每個模擬步代表的年數

## 脊椎動物

基因 `spine`（脊椎）與 `jaw`（下顎），一旦取得就不會因小突變而失去，決定脊椎動物的出現與型態：
- 三種大突變依序開啟：「脊索」→「下顎」→「四肢」（陸地場景才會長四肢）
- 脊椎讓大體型與高速游動的代謝成本下降，下顎提高捕獵成功率並能吞下更大的獵物
- 水中畫成魚（無頜魚、甲冑魚、肉鰭魚、鰻、鯊、燈籠魚），陸地畫成兩棲類（蛙、蠑螈、蚓螈、洞螈、迷齒獸）
- `vertRate`：脊椎動物突變率倍數，頁面左側「演化節奏」滑桿可即時調整
- `capP`：掠食者的族群上限，跟草食者 `capH` 分開計算

## 爬行類與鳥類

接在魚類、兩棲類之後的兩個大突變：
- 「羊膜卵」（基因 `amnio`）：陸地上需要四肢、水中需要肉鰭或下顎才會發生。爬行類不再依賴潮濕環境、代謝較低、能長得更大，但怕冷。深海裡會變成重返海洋的海生爬行類（魚龍、蛇頸龍、滄龍、海龜、海蛇），用肺呼吸，越往深處換氣成本越高；陸地上是蜥蜴、蛇、龜和恐龍（雷龍、暴龍、劍龍、甲龍、迅猛龍）
- 「羽毛與翅膀」（基因 `wing`）：只在高山場景、由爬行類演化而來。鳥類恆溫不怕冷、飛行速度快、地面掠食者很難抓到，但飛行耗能高、不能披甲。依食性與體型命名為雀、雷鳥、伯勞、鷹、禿鷲
- 世界畫面用「物種精靈圖快取」（ui.js 的 `getSprite`）：每個物種預先畫好 6 張動畫影格再貼上，大量脊椎動物時仍維持流暢

## 彗星場景

`SCENES.comet` 是太空場景：細胞落在短週期彗星的冰核表層，溫度、星光、液態水隨橢圓軌道週期變化（`orbitNow()`、`computeComet()`）。
彗星專屬參數為輻射、重力、軌道偏心率；專屬基因為隱生休眠（`dorm`）、黑色素屏蔽（`shield`）、太陽帆（`sail`），另有薄膜帆、黑色素堆積、隱生基因三種大突變。
- `boost`：彗星夏季的生長倍率，調高會演化得更快
- `period`：一圈公轉的模擬步數
