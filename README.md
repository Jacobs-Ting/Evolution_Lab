# 深時培養皿

生命演化模擬網頁遊戲原型。直接用瀏覽器打開 `index.html` 即可遊玩，不需要伺服器或安裝套件。

## 檔案結構

- `index.html`：版面與樣式（CSS 內嵌）
- `js/sim.js`：演化模擬核心（環境場、基因組、突變、代謝、捕食、物種分化與命名、標本卡解說）
- `js/draw.js`：依基因程序生成生物外觀（體節、附肢、觸手、眼睛、甲殼、棘刺、發光器、葉狀體、輻射對稱體）
- `js/ui.js`：畫面繪製、場景背景、參數滑桿、地質事件、標本卡、生命之樹、演化紀事

## 常用調整點（js/sim.js）

- `SPLIT`：物種分化門檻，調小會更常出現新物種
- `mutate()`：突變機率與幅度、大突變（體節複製、新附肢、眼點複製、觸手增生、吞噬作用）的機率
- `step()` 中的 cost / gain：各性狀的代謝成本與環境效益，是天擇方向的關鍵
- `capA` / `capH`：生產者與消費者的族群上限，影響效能與生態平衡
- `TICK_YEARS`：每個模擬步代表的年數

## 彗星場景

`SCENES.comet` 是太空場景：細胞落在短週期彗星的冰核表層，溫度、星光、液態水隨橢圓軌道週期變化（`orbitNow()`、`computeComet()`）。
彗星專屬參數為輻射、重力、軌道偏心率；專屬基因為隱生休眠（`dorm`）、黑色素屏蔽（`shield`）、太陽帆（`sail`），另有薄膜帆、黑色素堆積、隱生基因三種大突變。
- `boost`：彗星夏季的生長倍率，調高會演化得更快
- `period`：一圈公轉的模擬步數
